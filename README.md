# MiLeVR Sudoku website

Public German/English website: https://milevr.github.io/milevr-sudoku/

GitHub Pages serves the static files from `main`. No build step or external dependencies are needed.

- `index.html`: game information, version 1.1 availability and screenshot gallery.
- `styles.css`: responsive layout and existing MiLeVR colours.
- `screenshots/`: the five developer-provided version 1.1 screenshots, stored as JPG for smaller web downloads. Store PNG originals are kept separately.
- `privacy-policy.html`: German and English privacy policy.

Version 1.1 was approved and publicly released on the Meta Horizon Store on 11 October 2026, as confirmed by the developer's dashboard screenshot. The German/English release notice and section labels reflect its availability.
